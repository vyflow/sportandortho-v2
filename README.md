# Sports & Ortho v2

A standalone website design concept for Sports & Ortho Physical Therapy. Includes the homepage, Our Team directory, natural-color photography and a cinematic four-scene hero film.

## Preview locally

No build step or package installation is required. From this folder:

```sh
python3 -m http.server 4178
```

Open http://localhost:4178/ in your browser.

## Review status

This is a review concept, separate from the production website. Appointment forms are demonstrations: nothing is transmitted, saved or booked. The hero film is AI-generated with fictional adult subjects and requires clinical review before public use. It loops silently and respects reduced-motion preferences. No visible playback button is included, as requested.

The included 1080p web film was derived from a 4K upscale. Full-resolution masters, generation credentials and internal project records are not included.
